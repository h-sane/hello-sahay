# Sahay Desk (Vite)

Hospital reception dashboard from a teammate's prototype, wired to the Hello Sahay API. Endpoint map: `docs/FRONTEND_INTEGRATION.md`.

```bash
npm install && npm run dev      # http://localhost:5173, proxies /api to :8001
```

Demo login: `desk7@sahay.demo` / `demo1234` (facilities 7 to 10 are partners). Set `SAHAY_API_ORIGIN` if the API is elsewhere, `VITE_API_URL` for a hosted build.
